# student-registration-java

## Description
Java Maven console application for managing students inside school classes. It includes class creation, student registration, removal, search by enrollment number, and listing operations.

Academic context: object-oriented programming exercise focused on classes, encapsulation, lists, and simple domain modeling.
## Tech Stack
- Java
- XML
- Maven
- NetBeans
- Single-language project

## Structure
- `src/main/java/com/arthur/cadastroalunos/CadastroAlunos.java`: main entry point or primary source file.
- `pom.xml`: Maven project configuration.
- `src/`: Java source tree.

## How to Run
mvn exec:java
